# Options Greeks Logo System

This folder contains a full logo pack with 5 design concepts and production-ready variants.

## Concept Directions (Design Team)

- `concept-01-quant-core-*`
  - Positioning: precision analytics, chart-first identity.
- `concept-02-delta-shield-*`
  - Positioning: risk protection and hedging confidence.
- `concept-03-orbit-gamma-*`
  - Positioning: dynamic Greeks interactions and market motion.
- `concept-04-volatility-wave-*`
  - Positioning: volatility flow and term-structure energy.
- `concept-05-risk-lens-*`
  - Positioning: decision intelligence and execution scrutiny.

Each concept includes:
- `*-mark.svg` (icon only)
- `*-lockup.svg` (icon + wordmark)
- `*-favicon.svg` (compact browser icon)

## Primary Brand Set (selected default)

- `logo-primary.svg` (main lockup)
- `logo-mark.svg` (main mark)
- `logo-favicon.svg` (favicon)
- `logo-mono-light.svg` (light background)
- `logo-mono-dark.svg` (dark background)

## Usage Guidance

- Website header: use `logo-mark.svg` + text wordmark for responsive flexibility.
- Browser tab: use `logo-favicon.svg`.
- Social preview / slides: use `logo-primary.svg`.
- Print or one-color exports: use mono variants.

## Recommended Minimum Sizes

- Mark: 24px (UI), 48px (marketing)
- Lockup: 180px minimum width on web
- Favicon: 32px preferred raster export from SVG
